# Changelog — nano25 binary demos

Notable changes to the published demos, newest first. Demo versions follow the Fusion SDK they are
built with. Each entry reads `ID · area · subject` : the ID is unique across releases and never
reused, so that a change can be referred to by its ID.

----------------------------------------------------------------------------------------------------

## [4.3.72] - 2026-10-14

### Changed

- **DEMO-0003 · All · SDK 4.3** — demos rebuilt against Fusion SDK 4.3.72 ; they require the
  v4.3 firmware.

----------------------------------------------------------------------------------------------------

## [4.2.70] - 2026-08-30

- **DEMO-0002 · All · SDK rebuild** — no functional change : demos rebuilt as-is against Fusion
  SDK 4.2.70.
